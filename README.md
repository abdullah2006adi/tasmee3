# كشف التسميع

موقع لتسجيل تسميع الطلاب للسور القرآنية:

- كل آية عليها درجتان: **2** بلا تذكير، **1** مع تذكير، **0** لم يسمع.
- تحت كل آية خانة لخطأ النطق، وكل خطأ نطق ينقص الدرجة النهائية درجة واحدة.
- النسبة = المجموع × 100 ÷ (عدد الآيات × 2)، والدرجة النهائية = النسبة − عدد أخطاء النطق.
- درجة الشفوي من 6: ‏80 فأكثر = 6، ‏70 = 5، ‏60 = 4، ‏40 = 3، ‏20 = 2، أقل = 1.
- ترتيب الطلاب حسب أفضل تسميع، وتصدير الكشف إلى Excel.

## النشر على GitHub Pages

1. ادخل إلى github.com واضغط **New repository**، وسمِّه مثلاً `tasmee3`، واجعله **Public**.
2. اضغط **uploading an existing file** وارفع الملفين `index.html` و`quran.js` ثم **Commit changes**.
3. من **Settings ← Pages** اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو دقيقتين يعمل الموقع على: `https://اسم-حسابك.github.io/tasmee3/`
